Descripcion: Desarrollo e implementación del Tipo de Dato Abstracto Cola siguiendo la filosofía FIFO (First In, First Out), 
construido desde cero mediante una estructura dinámicade nodos enlazados por referencias en Java. El proyecto integra una
interfaz gráfica interactiva desarrollada con Java Swing, permitiendo visualizar en tiempo real el comportamiento de la
estructura, validar datos de entrada y ejecutar las operaciones fundamentales: encolar, desencolar, consultar frente, 
verificar estado, obtener tamaño y vaciar. La arquitectura sigue un diseño en tres capas (dominio, estructura y 
presentación), garantizando la separación de responsabilidades y el cumplimiento de los principios de la Programación 
Orientada a Objetos.


-Instrucciones para ejecutar proyecto-

-Descargar o clonar el repositorio
-Abrir el proyecto en Apache NetBeans
-Ejecutar
-Utilizar la interfaz grafica y llenar los campos para las operaciones correspondientes
